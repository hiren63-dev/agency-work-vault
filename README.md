# Agency Work Vault & Portfolio Codebase

Consolidated production repository containing the complete interactive **Work Section** (from `hiren.website/work`) and the 5 featured production client projects, engineered for seamless migration to the new agency portfolio.

## 📦 What is inside this Vault:

1. **`WORK_SECTION_MASTER_DOSSIER.md`**: Complete architectural breakdown, database configurations, and deployment guide.
2. **`component/`**: Drop-in Work Section for your new agency portfolio:
   - `WorkSection.tsx` (React / Next.js / Tailwind component)
   - `work_section.html`, `work.css`, `work.js` (Vanilla stack)
3. **`assets/work/`**: High-resolution WebP desktop and mobile device previews.
4. **`demos/`**: Self-contained interactive iframe sandboxes for **Pulse Studio** and **BuddyDesk**.
5. **`migrated_projects/`**: Complete, sanitized source code for all 5 client projects:
   - **`bnps/`**: Enterprise legal & tax practice website (Zero-bundle ESM).
   - **`harsh-manek/`**: Financial firm portal (React, Tailwind, Supabase).
   - **`kadivar-associates/`**: Architectural & tax practice (Next.js 15, Framer Motion, Lenis).
   - **`pulse-gms/`**: Multi-gym management system (Node.js API, PWA, Web Push).
   - **`buddydesk/`**: Startup CRM & team workspace (React, Firebase, Electron, MCP).
6. **`deploy-to-new-vercel.ps1`**: Turnkey script to deploy all 5 projects to your new Vercel account.
